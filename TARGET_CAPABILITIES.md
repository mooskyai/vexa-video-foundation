# Target Capability Reference

This project does not use Seedance or Wan model weights. These systems are referenced only to define a capability bar as of September 2026.

## Seedance 2.5 target class

Public ByteDance material describes 30-second single-generation audio-video creation, multi-round extension, stronger long-form storytelling, multimodal reference generation and editing/production controls.

Reference: ByteDance Seed, "Introducing Seedance 2.5", 2026-07-31.

## Wan 3.0 target class

Public Alibaba Cloud documentation describes up-to-30-second generation, 30 fps output, native dialogue/BGM/sound effects, 480p/720p/1080p options, multimodal references, first/last-frame control, editing and extension.

Reference: Alibaba Cloud Model Studio, Wan3.0 Video Generation documentation, updated 2026-09-28.

## Project interpretation

"Targeting Seedance 2.5/Wan 3.0 level" means eventually competing across the capability dimensions above. It does not imply architectural similarity, access to proprietary training data, or current quality parity.
